Lucky1SUI 是一个构建在 Sui 公链上的彩票 DApp：Move 智能合约管理奖池与开奖，React 前端完成购彩交互，全流程上链、公开透明。**本作品获得 Sui Overflow 2025 全球前 100。**

## 主要特性

1. **Sui Overflow 2025 全球前 100**：在全球性黑客松中脱颖而出，从 0 到 1 完成链上产品的设计、合约与交付。
2. **Move 合约设计**：Lottery / LotteryPool / Ticket 三类对象——系统初始化最新一期奖池，后续每期结束后自动滚存生成新一期。
3. **购彩规则**：1 SUI 兑换 1 张奖券，每张奖券最多选 10 个号码，中奖与号码一一对应。
4. **合约单元测试**：核心逻辑带完整测试，保障资金安全。
5. **现代 dApp 前端**：React + TypeScript + @mysten/dapp-kit，Vite 构建，Radix UI 组件。

## 技术栈

- Sui 公链 + Move 智能合约
- React + TypeScript + Vite
- @mysten/dapp-kit 钱包与链上交互
- Radix UI
